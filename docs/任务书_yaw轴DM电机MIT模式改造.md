| 项目 | 内容 |

| 软件基线 | `Skywalker/Application/Src/app_standard.c` 当前版本 |

## 1. 任务目标

将 Standard 机器人 Yaw 轴达妙 J4310 电机从速度模式
`kDmMotorModeVelocity` 改为 MIT 模式 `kDmMotorModeMit`，使用 MIT 帧中的
目标位置、目标速度、位置增益、速度增益和前馈力矩控制电机。

本任务完成后应满足以下目标：

1. Yaw 电机和主控均实际运行在 MIT 模式，控制帧 ID 由 `0x206` 变为
   `0x006`；
2. 遥控器、键鼠、底盘小陀螺及视觉控制入口保持可用；
3. 上电、遥控器离线、反馈丢失、电机报错和重新使能时无位置突跳、持续发力或飞车；
4. MIT 参数可安全整定，正常运行时无持续振荡、明显超调或异常发热；
5. 保持现有 Yaw 角度、角速度、力矩和温度反馈解析及视觉上报能力。

本次不修改 Pitch 轴 GM6020、底盘电机和发射机构控制；除非测试发现协议实现缺陷，
不重写通用 DM 电机驱动。

## 2. 当前状态与改造边界

### 2.1 当前控制链路

| 环节 | 当前实现 | 代码位置 |
| --- | --- | --- |
| 电机对象 | `DmMotor yaw_motor` | `app_standard.c` 的 `StandardApp` |
| 初始化 | J4310、速度模式、CAN ID `0x06`、Master ID `0x11` | `StandardMotorInit()`，当前约 L325 |
| 实际发送 ID | `0x06 + 0x200 = 0x206` | `DmMotorTxId()` |
| 使能 | 初始化完成后发送 `DmMotorPackEnable()` | `StandardSharedInit()`，当前约 L376 |
| 控制周期 | 2 ms | `kStandardGimbalPeriodMs` |
| 手动控制 | 输入积分为场地系 `target_yaw_angle`，再由角度误差计算 `yaw_rate` | `StandardGimbalControl()` |
| 视觉控制 | 当前直接采用 `g_vision_to_gimbal.yaw_velocity` | `StandardGimbalControl()`，当前约 L540 |
| 控制发送 | `given_omega` + `DmMotorPackVelocity()` | 当前约 L587～L593 |
| 停止发送 | `given_omega = 0` + 速度帧 | 当前约 L648～L676 |
| 反馈 | 解析位置、速度、力矩、MOS/转子温度和错误码 | `StandardFdcan2RxCallback()`、`DmMotorUpdate()` |

当前结构为：

```text
场地系目标角 - 底盘航向
          ↓
    MCU 侧位置 P 环
          ↓
     目标电机速度
          ↓
    DM 内部速度闭环
```

目标结构为：

```text
场地系目标角 - 底盘航向 → 电机坐标系目标位置 p_des
相对目标角速度             → 目标速度 v_des
kp、kd、前馈力矩            → DM 内部 MIT 阻抗控制器
```

### 2.2 已具备的驱动能力

`dev_dm_motor.c/h` 已提供本任务所需的接口：

- `kDmMotorModeMit`；
- `DmMotorPackMit()`；
- `given_angle`、`given_omega`、`kp`、`kd`、`given_torque`；
- MIT 反馈解析和 Enable、Disable、ClearError、ZeroOffset 特殊命令。

因此主要改动位于应用层。底层驱动默认只补测试和输入保护，不改变协议布局。

## 3. 协议与电机端前置条件

### 3.1 MIT 控制律

达妙手册给出的 MIT 控制含义为：

```text
torque_cmd = kp × (p_des - p) + kd × (v_des - v) + t_ff
```

其中 `p`、`v` 来自电机反馈，`t_ff` 为前馈力矩。位置控制时 `kd` 不得为 0；
零力矩调试帧必须同时满足 `kp = 0`、`kd = 0`、`t_ff = 0`。

当前驱动的映射范围如下，必须与达妙调试助手中的 P_MAX、V_MAX、T_MAX 一致：

| 字段 | 位宽 | 当前软件范围 |
| --- | ---: | ---: |
| `p_des` | 16 bit | `[-12.5, 12.5] rad` |
| `v_des` | 12 bit | `[-30, 30] rad/s` |
| `kp` | 12 bit | `[0, 500]` |
| `kd` | 12 bit | `[0, 5]` |
| `t_ff` | 12 bit | `[-10, 10] Nm` |

> 上述范围既参与量化，也参与限幅。电机端和软件端任一侧单独修改都会造成指令物理量错误，
> 因此参数变更必须成对记录、成对验证。

### 3.2 电机端配置检查

编码前先通过达妙调试助手读取并记录以下配置：

- 型号和固件版本；
- Control Mode：改为 MIT；
- CAN ID：`0x06`；
- Master ID：`0x11`；
- CAN 波特率：1 Mbps；
- P_MAX、V_MAX、T_MAX；
- 电流、过温、过压、欠压、过载及通信丢失保护阈值。

写入后重新上电并再次读取确认。若实际 ID 或量程与代码不同，先统一配置再继续。

`DmMotorTxId()` 在 MIT 模式下应返回 `0x006`。抓包时不得再出现该 Yaw 电机的
`0x206` 速度控制帧。

### 3.3 零点与机械范围确认

开始控制前必须确认：

- Yaw 正方向和电机编码器正方向；
- 云台机械中位对应的电机反馈角；
- 是否允许连续旋转，线束或滑环允许的最大圈数；
- 机械限位和软件允许角范围；
- 电机反馈角在跨圈时的实际变化方式。

禁止在普通开机流程中自动发送 `DmMotorPackZeroOffset()`。该命令会持久化改变电机零点，
只能在云台固定于机械中位、输出已解除且操作员明确执行校准时发送。

## 4. 目标控制方案

### 4.1 坐标定义

新增并明确以下量，所有角度单位均为 rad：

| 变量 | 含义 |
| --- | --- |
| `target_field_yaw` | 云台在场地坐标系中的目标航向 |
| `chassis_yaw` | 底盘在场地坐标系中的航向 |
| `target_relative_yaw` | 云台相对底盘的目标角 |
| `yaw_motor_zero_angle` | 本次启动时相对角为 0 对应的电机反馈角 |
| `yaw_motor_ratio` | 电机反馈角 / 云台机械角，直驱时通常为 1，仍须实测确认 |
| `p_des` | 发送给电机的 MIT 目标位置 |
| `v_des` | 发送给电机的 MIT 目标速度前馈 |

基本关系为：

```text
target_relative_yaw = target_field_yaw - chassis_yaw
p_des = yaw_motor_zero_angle
        + kStandardGimbalYawMotorSign × yaw_motor_ratio × target_relative_yaw
v_des = kStandardGimbalYawMotorSign
        × yaw_motor_ratio × (target_field_yaw_rate - chassis_yaw_rate)
```

`yaw_motor_zero_angle` 应在收到第一帧有效 Yaw 电机反馈后在 RAM 中捕获，随后把首个
`p_des` 对齐到当前反馈角。未收到有效反馈前不得投入非零 `kp`。

### 4.2 角度连续性

不能直接把 `StandardWrapPi()` 的结果原样作为 `p_des`。在 `+π/-π` 边界，目标值会产生
约 `2π` 的跳变，MIT 位置环可能驱动电机突然反向旋转。

实现时应完成以下处理：

1. 基于当前电机位置，在 `target_relative_yaw + 2kπ` 的等价候选中选择距离当前位置最近者；
2. 候选值必须位于实际配置的 P_MIN/P_MAX 之内；
3. 对最终 `p_des` 增加速度/斜率限制，禁止视觉或模式切换产生一步大角度命令；
4. 找不到合法候选时进入位置范围故障处理，不得仅依赖底层静默钳位；
5. 若机构要求连续多圈，必须先台架确认电机内部位置和反馈的跨圈规则，再确定解包、回绕或
   受限角策略。不得在运动中通过“自动保存零点”规避量程问题。

### 4.3 各输入模式的处理

- 遥控器 / 键鼠：继续用输入角速度积分得到场地系目标角，再转换为 `p_des`；输入角速度可
  作为 `v_des` 前馈。
- 底盘小陀螺：保持当前场地系指向逻辑，`v_des` 中补偿底盘角速度。
- 视觉：当前代码只使用 `yaw_velocity`，而协议中的 `yaw` 注释仍为“按业务模式解释”。
  实施前需和视觉端确认 `yaw` 是绝对角、角度误差还是未使用字段。默认兼容方案是将
  `yaw_velocity` 限幅后积分到 Yaw 目标角，同时作为速度前馈；不得因改为 MIT 而让视觉模式
  只更新速度、不更新目标位置。
- 模式切换：从手动切入视觉或从视觉退出时，用当前电机位置重置/对齐目标轨迹，确保
  `p_des` 连续。

若仅设置 `kp = 0`、使用 `kd` 和 `v_des`，MIT 帧也能实现速度型控制，但这只能作为通信与
方向验证阶段，不作为本任务最终的 MIT 位置控制验收状态。

### 4.4 MIT 参数和命令约束

在 `app_standard.c` 的 Yaw 常量区集中定义：

- 运行 `kp`、`kd`；
- 最大 `p_des` 变化率；
- `v_des` 限幅；
- `t_ff` 限幅，初始为 `0 Nm`；
- 反馈超时阈值；
- 增益软启动时间；
- 允许温度和位置范围。

所有送入 `DmMotorPackMit()` 的浮点量均需先检查 `isfinite()`。出现 NaN/Inf 时立即发送
零力矩命令并锁存软件故障，禁止把异常值直接转换为定点数。

建议分阶段使用参数：

| 阶段 | `kp` | `kd` | `t_ff` | 用途 |
| --- | ---: | ---: | ---: | --- |
| 通信验证 | 0 | 0 | 0 | 验证帧、ID、反馈和零输出 |
| 方向验证 | 0 | 较小非零值 | 0 | 用小幅 `v_des` 验证方向 |
| 首次位置闭环 | 低值 | 非零低值 | 0 | 小角度阶跃，观察阻尼 |
| 正常运行 | 台架整定值 | 台架整定值 | 默认 0 | 整车验收 |

首次位置闭环可从 `kp = 1～3`、`kd = 0.05～0.2` 的保守区间开始，每次只调整一个参数。
该区间仅用于台架起调，不得直接视为最终值。最终参数必须记录在第 9 节的调试表中。

### 5.2 安全状态机

至少覆盖以下状态：

```text
WAIT_FEEDBACK → ALIGN_ZERO → ENABLE → GAIN_RAMP → RUNNING
      ↑                                           ↓
      └────────── ZERO_OUTPUT / DISABLED ← FAULT / SAFE / OFFLINE
```

- `WAIT_FEEDBACK`：MIT 增益为 0，不进行位置闭环；
- `ALIGN_ZERO`：捕获当前反馈角，将首个 `p_des` 与当前位置对齐；
- `ENABLE`：发送一次 Enable，随后持续发送 `kp=kd=t_ff=0` 的 MIT 零力矩帧；
- `GAIN_RAMP`：目标固定在当前角，`kp/kd` 在设定时间内渐增；
- `RUNNING`：执行正常目标轨迹；
- `FAULT/SAFE/OFFLINE`：立即撤销 MIT 输出，发送零力矩帧后按策略 Disable，故障原因锁存。

建议反馈超时初值为 20 ms，即连续丢失约 10 个控制周期后进入故障。最终阈值根据抓包得到的
真实反馈周期确定，并应明显大于正常抖动、明显小于可能造成危险的失控时间。

当前 `DmMotorState.is_enabled` 只反映软件是否打包过 Enable/Disable，不是电机实际使能反馈，
不能单独作为健康状态依据。

### 5.3 驱动层检查和测试

`DmMotorPackMit()` 的位布局与手册一致，原则上无需改写。需补充或执行以下测试：

1. 最小值、零值、最大值及越界钳位测试；
2. 浮点到定点量化误差测试；
3. `DmMotorTxId()` 在 MIT 模式下返回 `0x006`；
4. 反馈位置、速度、力矩和错误码解析回归测试；
5. 空指针和非有限浮点输入保护测试。

按当前范围和当前截断算法，`p=v=kp=kd=t=0` 的 MIT 帧应为：

```text
7F FF 7F F0 00 00 07 FF
```

因此“零力矩 MIT 帧”不等于 8 个 `0x00`。测试应校验物理量语义，不能用全零字节替代。

## 6. 安全要求

1. 首次上电调试必须架空负载或解除传动，保留硬件急停和断电手段；
2. 未确认方向前，`kp` 必须为 0；方向验证只允许小 `v_des`、短时间点动；
3. 未收到有效反馈、反馈超时、位置越界、输入为 NaN/Inf 或电机 `error_code != 0` 时，
   禁止非零位置增益和前馈力矩；
4. 进入遥控器安全模式时，MIT 的 `kp`、`kd` 和 `t_ff` 必须全部清零。只把
   `given_omega` 置 0 并不等于零输出；
5. 清错后不得直接恢复旧目标。必须先确认反馈正常，将目标对齐当前位置，再软启动增益；
6. 禁止在带输出状态下写零点，禁止用运行时自动标零处理跨圈问题；
7. 调试期间限制电源电流和目标变化率，持续监视 MOS 温度、转子温度、反馈力矩和错误码。

电机反馈错误码的处理记录至少应覆盖：`0x8` 超压、`0x9` 欠压、`0xA` 过流、
`0xB` MOS 过温、`0xC` 线圈过温、`0xD` 通信丢失和 `0xE` 过载。故障原因未消失时
不得循环清错或恢复增益。

| 底盘静止 | 云台能稳定保持目标角 |
| 底盘旋转 / 小陀螺 | 云台场地系指向误差 ≤ 5°，无周期性抽动 |
| 手动 ↔ 视觉切换 | 切换瞬间目标连续，无明显冲击 |
| 安全模式 ↔ 恢复 | 退出安全模式后先对齐再恢复增益，无回零冲击 |
| 视觉上报 | Yaw 角和角速度方向、单位及刷新率不退化 |

## 8. 风险清单

| 风险 | 可能后果 | 控制措施 |
| --- | --- | --- |
| 电机端仍是速度模式 | `0x006` 帧不生效或行为异常 | 调试助手写入 MIT，掉电重读确认 |
| 软件与电机量程不同 | 指令缩放错误，可能满力矩 | P/V/T 范围逐项核对并记录 |
| 首帧目标未对齐 | 上电瞬间猛转 | 等首帧反馈、目标对齐、增益软启动 |
| `±π` 目标跳变 | 电机突然反转一整圈 | 最近等价角 + 目标斜率限制 |
| 方向符号错误 | 正反馈飞车 | `kp=0` 小速度点动验证 |
| `kd=0` 直接位置控制 | 振荡或失控 | 位置闭环必须使用已验证的非零 `kd` |
| 停止时只清速度 | `kp` 仍产生保持力矩 | 同时清 `kp/kd/t_ff` 或 Disable |
| 循环重复清错 | 故障反复使能，掩盖根因 | 故障锁存和受控恢复状态机 |
| 自动写零点 | 永久偏移、上电冲击 | 仅在受控校准流程执行 |
| 视觉语义不明确 | 视觉模式漂移或突跳 | 联调前确认 `yaw/yaw_velocity` 定义 |
